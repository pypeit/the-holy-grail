# Caption for `pr_figure_2panels.png`

A calibration exposure from the Levy spectrometer on the Automated Planet
Finder (APF) telescope at Lick Observatory, shown before and after wavelength
calibration. The spectrometer spreads the light of a thorium–argon lamp into
55 stacked strips, called echelle orders. Each strip covers a narrow slice of
the spectrum, and every bright dash is a single emission line from the lamp.
**Left:** the detector image as recorded (cleaned for display). It is only a
grid of pixel brightnesses, with no labels saying which wavelength each pixel
saw. **Right:** the same image after the open-source PypeIt pipeline assigned
a wavelength to every pixel. Each pixel is colored by that wavelength, from
deep red at the top (about 690 nm) to violet at the bottom (about 380 nm).
The "Holy Grail" project aims to automate this pixel-to-wavelength mapping
for any spectrograph, without expert input.
